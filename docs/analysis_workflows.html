Analysis Workflows¶

ROI Fitting Workflow¶

  1. Load a dataset and confirm the heatmap looks physically reasonable.

  2. Draw a ROI around the event or background period.

  3. Select a fitting method.

  4. Run the fit.

  5. Inspect the heatmap markers, size-distribution markers, and diameter strip.

  6. Fit a growth-rate line when the fitted points represent a coherent growth trajectory.

  7. Save the session.

Fit Methods¶

Appearance Time

Estimates the first meaningful appearance of particles in each diameter channel. Useful for leading-edge event timing.

Mode Diameter

Fits lognormal modal structure and tracks modal diameter evolution.

Gaussian LSQ

Fits a constrained Gaussian curve to time-series or distribution structure.

GMM Fit

Uses mixture modeling where multiple overlapping structures may be present.

MCC Cross-Correlation

Computes growth rate from time lag between size channels inside the selected ROI. Use the MCC diagnostic plot to check whether the upper diameter channel plausibly lags the lower diameter channel.

Surface and Volume Density¶

Surface and volume density views are calculated through the aerosol-functions surface and volume distribution helpers. Color-limit text boxes use compact scientific formatting so small physical values do not display as zero.

Large Dataset Interaction¶

The display path is optimized separately from the analysis path. Heatmap and overlay rendering use display-oriented sampling so interactive changes remain responsive. Fitting and ROI calculations continue to use the loaded dataframe instead of the downsampled display buffer.
