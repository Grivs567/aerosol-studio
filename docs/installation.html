Installation¶

Requirements¶

  • Python 3.10 or newer.

  • A modern browser such as Chrome, Edge, Firefox, or Chromium.

  • A graphical desktop session. The interactive Bokeh GUI is intended for a browser.

Create an Environment¶

From the Aerosol Studio folder:

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .

Launch the App¶

On Windows:

run_aerosol_studio.bat

On macOS/Linux:

./run_aerosol_studio.sh

If an archive tool does not preserve executable permissions, the same launcher can be run with bash run_aerosol_studio.sh.

After installation, the package provides a console entry point that launches the canonical Bokeh application:

aerosol-studio
