Troubleshooting¶

The Browser Does Not Open¶

The Bokeh server may still be running even if the browser did not open. Look for the local URL in the terminal, usually http://localhost:5006.

Port Already in Use¶

Use a different port:

python -m bokeh serve --port 5007 --show src/aerosolstudio/main.py

The Heatmap Looks Shifted in Time¶

Check the source timezone control and reload the data. CSV files often do not store timezone metadata, and NetCDF files may vary by instrument convention.

Surface or Volume Color Limits Look Too Small¶

Surface and volume density values are physically small. The app formats these values in scientific notation where needed. If an event is still hidden, use manual color min/max limits.

Overlay Updates Feel Slow¶

Overlay plotting uses the currently visible time range and display sampling. Zoom into the time range of interest before adjusting overlay settings on very large datasets.

Save or Export Opens a Native Dialog¶

Some save/export actions use operating-system file dialogs. In normal desktop use this is expected. In headless automation or remote server use, prefer manual testing or future browser-native save/load support.

MCC Gives a Failed Result¶

MCC is sensitive to the selected ROI, the Fit Dp min/max range, missing data, and whether the larger size channel actually lags the smaller channel. Use the MCC diagnostic plot to inspect the two normalized channels before trusting a growth-rate result.
