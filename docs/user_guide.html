User Guide¶

Loading Data¶

Aerosol Studio starts with default CSV and NetCDF instrument panels. Each panel keeps its own loaded data, ROIs, overlays, fit results, and session state.

CSV data should be a table where rows are timestamps and columns are particle diameter bins. NetCDF data should contain a time axis, a diameter axis, and a 2-D size-distribution variable.

Before loading, check:

  • Source timezone: the timezone represented by the raw timestamps.

  • Diameter unit: nm, um, or m.

  • Data type: dN/dlogDp or per-bin number concentration.

Internally, diameter columns are converted to metres and loaded values are normalized to the representation expected by the analysis pipeline.

Heatmap Views¶

The heatmap is the primary analysis view. It displays time on the x-axis, particle diameter on the y-axis, and a color-mapped value in each time-diameter cell.

Display modes include:

  • dN/dlogDp.

  • Number concentration.

  • Surface density.

  • Volume density.

Changing the display mode affects the image and color scale only. ROI masks, fits, and growth-rate calculations continue to use the canonical loaded data.

Regions of Interest¶

ROIs define the time-diameter region used for fitting. Use freehand drawing for events with irregular shape and rectangular drawing for simple bounded regions.

The selected polygon controls which stored fit results are shown in the linked panels. Polygon labels should be short but meaningful, for example NPF event or background period.

Linked Plot Panels¶

The local plot tabs below the heatmap are linked to heatmap clicks:

Size Distribution

Shows the particle-size distribution at the clicked time.

Diameter Strip

Shows the time series at the selected or clicked diameter.

MCC Cross-Correlation

Shows MCC results and a compact diagnostic plot. The diagnostic plot compares normalized lower-Dp and upper-Dp time series using the current Fit Dp min/max range.

Variable Overlays¶

Variable overlays add a secondary y-axis time series over the heatmap. Typical uses include total concentration, condensation sink, coagulation sink, and PM metrics. Overlay IDs use the var_0, var_1 naming pattern.

Each overlay line has its own method, diameter or density inputs when relevant, line color, style, thickness, visibility, y-range, and export action.

Session Save and Load¶

Session files preserve analysis state, including:

  • Instrument metadata.

  • ROI polygons.

  • Fit points and growth-rate lines.

  • Variable overlays.

  • MCC results.

For reproducibility, keep the original data files with the saved session file.
