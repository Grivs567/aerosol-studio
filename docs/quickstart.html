Quick Start¶

  1. Start Aerosol Studio.

    On Windows:

    run_aerosol_studio.bat

    On macOS/Linux:

    ./run_aerosol_studio.sh

  2. Load a dataset.

    • Use CSV_1 for text tables.

    • Use NetCDF_1 for NAIS-style NetCDF files.

    • Check the timezone, diameter unit, and data type before pressing Load.

  3. Inspect the heatmap.

    • Use the heatmap view selector to switch between dN/dlogDp, number concentration, surface density, and volume density.

    • Adjust color limits if the automatic range hides the event structure.

  4. Draw a ROI.

    • Use freehand drawing for event-shaped regions.

    • Use rectangular ROI drawing for simple time-diameter windows.

  5. Run a fit.

    • Select a fit method.

    • Press Run Fit.

    • Inspect markers on the heatmap and in the size-distribution panel.

  6. Inspect linked panels.

    • Size Distribution shows a time slice across all diameters.

    • Diameter Strip shows a time series at one diameter.

    • MCC Cross-Correlation shows MCC results and a diagnostic comparison of the lower and upper diameter channels.

  7. Save the session.

    Use the ROI/session save control to preserve polygons, fit points, growth rates, overlays, and MCC results.
